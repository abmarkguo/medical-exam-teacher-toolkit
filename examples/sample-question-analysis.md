# 示例：单题精准分析 · Sample Single-Question Analysis

> 对应 Module B。以一道临床执业 A2 题演示五维分析模型。

---

## 题头

- 题号：CL-2025-A2-0142
- 题型 / 系统 / 疾病：A2 / 心血管系统 / 急性心肌梗死
- 来源：RECALL（考生回忆版） / 置信度：中

## 题干（回忆版）

男，58 岁。持续性胸骨后压榨样疼痛 3 小时，伴大汗、恶心，含服硝酸甘油不缓解。
查体：BP 90/60 mmHg，心率 102 次/分，律齐。心电图：V1–V4 导联 ST 段抬高。
最可能的诊断是：

- A. 稳定型心绞痛
- B. 急性心肌梗死
- C. 急性心包炎
- D. 主动脉夹层
- E. 肺栓塞

**答案：B**

## 1. 考点映射

- 大纲条款：临床执业 · 心血管系统 · 急性心肌梗死临床表现与诊断
- 人卫版：《内科学》第10版 · 第三篇 循环系统疾病
- 关联指南：急性 ST 段抬高型心肌梗死诊疗指南

## 2. 认知层次

- 判定：**应用**
- 依据：给完整临床情境（症状+体征+心电图）要求诊断，属于知识迁移。

## 3. 难度

- 等级：**中**
- 归因：典型表现，但需排除主动脉夹层（血压差异/撕裂痛）与肺栓塞（呼吸困难/低氧）。

## 4. 命题陷阱

| 选项 | 正/误 | 设计逻辑 |
|------|-------|----------|
| A | 误 | "含服硝酸甘油不缓解"直接排除稳定型心绞痛 |
| B | 正 | V1–V4 ST 抬高 = 前壁 MI |
| C | 误 | 心包炎多广泛 ST 抬高伴胸痛随呼吸加重 |
| D | 误 | 夹层为撕裂样痛、双上肢血压差 |
| E | 误 | 肺栓塞以呼吸困难、低氧、右心负荷为主 |

## 5. 学生易错点

- 错选 D：被"胸痛+低血压"带偏，忽略心电图定位。
- 纠正：先读心电图定"壁段"，再结合症状。

## 6. 教学转化

> 一句话讲清：前壁 MI 看 V1–V4 ST 抬高；硝酸甘油不缓解 = 排除稳定心绞痛。
> 纠错话术："看到 ST 抬高先定位，别被血压带跑。"
