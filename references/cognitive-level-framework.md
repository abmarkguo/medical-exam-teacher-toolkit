# 认知层次分析框架 · Cognitive Level Framework

> 医师资格考试把试题按"认知层次"分为三类，是教师做精准分析与命题设计的核心标尺。

## 1. 三层定义（对齐 Bloom，适配医考）

| 层次 | 中文 | 定义 | 典型题型 | 教学策略 |
|------|------|------|----------|----------|
| 记忆 | Memory | 对事实、方法、过程、理论的识记 | A1、B1 | 口诀化、重复强化 |
| 理解 | Understanding | 转化、解释、推断知识意义 | A1、A2 | 对比表、机制图 |
| 应用 | Application | 把知识迁移到新情境解决实际问题 | A2、A3、A4 | 病例驱动、临床推理 |

> 医考中心数据：应用类长期约 50–55%，理解类近年上升，记忆类下降。
> 命题重心明显向"应用型人才"倾斜。

## 2. 如何判定一道题的认知层次

- 题干仅要求"下列哪项正确/错误"且为单一知识点 → **记忆**
- 题干给一小段机制/数据要求解释推断 → **理解**
- 题干给完整病例并要求诊断/处理/下一步 → **应用**
- 一道题可能跨两层：以**最高触发层次**为准（如记忆+应用 → 应用）。

## 3. 对教学的启示

1. **不要只划重点**。理解类/应用类占比高，"考前划重点"越来越不适用。
2. **分层训练**：记忆层用背诵+自测；理解层用对比；应用层用病例串。
3. **命题设计**：智能命制题时按比例配置三层（参考近年分布），避免偏记忆。

## 4. 标注规范

在题库元数据 `cognitive` 字段填：记忆 / 理解 / 应用。
批量统计时输出三层占比，作为考情报告核心指标之一。

## 5. 参考阈值（近年临床执业，估测）

| 层次 | 占比区间 |
|------|----------|
| 记忆 | 15–20% |
| 理解 | 28–40% |
| 应用 | 50–55% |

> 以上为培训机构基于考情反馈的估测值，正式数据以医考中心发布为准，标注 `【待核实】`。
