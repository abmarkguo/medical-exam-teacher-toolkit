# 趋势驱动智能命题 · Trend-Driven Question Generation

> 当教师需要"最新最有特色的考题"而真题有限时，基于大纲 + 趋势 + 认知层次
> 智能命制**特色模拟题**，并明确标注为"模拟"，绝不冒充真题。

## 1. 命制输入（必须提供）

- 目标系统 / 疾病 / 考点（映射 NHC 大纲条款）
- 题型（A1/A2/A3/A4/B1）
- 目标认知层次（记忆/理解/应用）与占比
- 难度（易/中/难）
- 特色要求（如"跨系统干扰""最新指南更新点""临床情境判断"）
- 来源标签：`AI-模拟`

## 2. 命制原则

1. **大纲内**：所有知识点必须落在 NHC 大纲与人卫版教材范围内。
2. **趋势对齐**：参考 2025/2026 命题转向——临床化、灵活化、应用化、智能化。
3. **认知配比**：按近年分布（记忆 15–20% / 理解 28–40% / 应用 50–55%）配置批次。
4. **陷阱真实**：干扰项要有"临床误区"依据，不是随便编造。
5. **标注清晰**：题头必须写 `【模拟题 · 非真题】` 与出处/依据。

## 3. 命制流程

```
选定考点(大纲条款) → 定认知层次/题型/难度 → 设计题干情境
     → 设计正确项 + 3-4 干扰项(含真实误区) → 写解析与考点溯源
     → 标注 metadata(同 question-record-template) → 入库待分析
```

## 4. 特色题类型（"最有特色"的来源）

| 特色类型 | 说明 | 示例 |
|----------|------|------|
| 指南更新题 | 基于最新临床指南变动点 | 某药用法由静脉改口服 |
| 跨系统干扰题 | 症状重叠的鉴别诊断 | 胸痛：心/肺/消化 |
| 临床情境题 | 教材未明写但临床常见 | 用药途径判断 |
| 递进病例串 | A3/A4 动态决策 | 入院→恶化→处理 |
| 认知陷阱题 | 高频易错点包装 | 数值单位/时间窗 |

## 5. 质量校验

- 命制后必须用 Module B（精准分析）逐题校验：考点/认知/难度/陷阱一致。
- AI 题 Confidence 标"中"，不进入"官方结论"层。
- 禁止生成与已公开真题逐字雷同的内容。
