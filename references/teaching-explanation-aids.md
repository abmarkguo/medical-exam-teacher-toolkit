# 考题讲解教学辅助 · Teaching Explanation Aids

> 把考题分析转化为可进课堂的教学资产：教案、课件大纲、讲稿、误区分层答疑。

## 1. 四类教学资产

| 资产 | 用途 | 模板 |
|------|------|------|
| 教案 (Lesson Plan) | 教师备课，考点—知识点—考题三位一体 | `templates/teaching-plan-template.md` |
| 课件大纲 (Slide Outline) | 课堂 PPT 结构 | `templates/lecture-outline-template.md` |
| 讲稿 (Lecture Script) | 教师口述，含误区分层提示 | 内嵌于教案/课件 |
| 误区分层答疑 (Q&A) | 面向不同水平学生的答疑 | `templates/qa-guide-template.md` |

## 2. 讲解的"三位一体"结构

> 考点（考什么）— 知识点（教什么）— 考题（怎么考）

课堂组织建议：**先梳理考点，后讲解考题**（递进式），让学生建立
"教什么 → 怎么教 → 考什么 → 怎么考"的闭环逻辑。

## 3. 三段式课堂模板（借鉴院校实践）

1. **章节考点清单**：明确本章执医考点与权重。
2. **典型真题拆解**：用 1–2 道真题演示"出题点 + 解题逻辑"。
3. **课后专项练测**：对标命题逻辑的过程性测验。

## 4. 讲稿要点

- 开宗明义：这道题考哪个大纲条款。
- 拆解题干：抓关键词（时间窗、数值、特征表现）。
- 逐项排除：为什么错项错（关联真实误区）。
- 升华：从单题到一类题的通用解题路径。
- 误区预警：学生最常踩的坑，提前点破。

## 5. 误区分层答疑

按学生水平给不同深度的答案：

- **基础弱**：先给结论 + 最简记忆口诀。
- **中等**：加机制解释 + 对比鉴别。
- **较强**：加临床情境延伸 + 命题陷阱拓展。

## 6. 与闭环衔接

讲解后收集学生答题数据 → 反馈回 Module A 题库 → 更新高频/易错标记 →
下一轮分析更精准。形成"教—学—评—改"持续改进。
