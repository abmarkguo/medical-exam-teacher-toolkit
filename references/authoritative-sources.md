# 权威来源与溯源规范 · Authoritative Sources & Citation Rules

> 医考内容必须准确、可溯源。本文件定义来源优先级与标注纪律。

## 1. 来源优先级（从高到低）

1. **国家卫健委（NHC）官方大纲**
   - 《医师资格考试大纲（2024年版）》
   - 2026 医学人文大纲修订内容
2. **人民卫生出版社（PMPH / 人卫版）**
   - 医师资格考试指导用书
   - 第10版教材（含变动考点标注）
3. **国家医学考试中心（NMEC / 医考中心）**
   - 官方研究报告
   - 创新性研究应用（智能命题、病例库、影像题库、自动组卷、智能审校）
4. **中华医学会临床诊疗指南**
   - 各专科临床诊疗指南 / 专家共识
5. **真题考情分析**
   - 主流培训机构考情复盘（标注出处与年份）
   - 院校教研公开数据（保留原始报道链接）

## 2. 标注纪律（强制）

| 情形 | 标注 |
|------|------|
| 引用官方大纲/教材/指南 | 注明文件全称 + 版本/年份 + 条款号 |
| 引用培训机构考情 | 注明机构 + 年份 + "考情反馈估测" |
| 引用院校教研数据 | 注明院校 + 学科 + 年份 + 原始报道 |
| AI 生成题 | 题头必须 `【模拟题 · 非真题】` |
| 无法溯源的官方数据 | 末尾标 `【待核实】` |

## 3. 禁止事项

- ❌ 编造官方分数、通过率、统考统计。
- ❌ 把 AI 模拟题 / 回忆版题冒充官方真题。
- ❌ 把单年波动说成长期趋势。
- ❌ 输出无来源的结论性断言。

## 4. 溯源模板（每条结论后）

```
【来源】NHC《医师资格考试大纲（2024年版）》· 临床执业 · 呼吸系统
【依据】人卫版《内科学》第10版 · 第X章
【备注】2026 医学人文修订新增点
```

## 5. 与题库 metadata 的关系

题库每条记录的 `source` 字段直接对应本规范第 1 节来源类型，
`confidence` 字段对应可信度分级。分析结论的可信度 = 来源等级 × 置信度。
