# 医考制度与命题导向（教师视角）· Exam System & Proposition Orientation

> 供医学院教师理解临床执业医师 / 助理医师资格考试的制度框架与命题走向，
> 作为考题获取、分析与讲解的权威底座。

## 1. 考试两阶段制度

| 阶段 | 名称 | 满分 | 合格线 | 有效期 | 形式 |
|------|------|------|--------|--------|------|
| 第一阶段 | 实践技能考试 | 100 | 60 | 2 年 | 多站式现场 |
| 第二阶段 | 医学综合笔试 | 600 | 360 | 当年 | 计算机化（CBT） |

- 技能合格后方可参加笔试；技能成绩 2 年内有效。
- 笔试采用机考，**跨题型不可回退**（进入下一题型后不能返回修改）。

## 2. 综合笔试题型（5 种）

| 题型 | 全称 | 特征 | 认知侧重 |
|------|------|------|----------|
| A1 | 单句型最佳选择题 | 单句陈述，单一知识点 | 记忆 / 理解 |
| A2 | 病例摘要型 | 一段病例 + 1 问 | 理解 / 应用 |
| A3 | 病例组型 | 共用题干，2–3 问递进 | 应用 |
| A4 | 病例串型 | 递进、可变情境 | 应用 / 综合 |
| B1 | 配伍题 | 多问共用备选答案 | 记忆 / 鉴别 |

> 2025 趋势：第四单元 A3 增多、A2 减少；A2 题干变长；B1 出现两小题同选一答案。

## 3. 单元与系统分值（临床执业，参考值）

- 第一单元：基础 + 人文（生理、生化、病理、药理、伦理、法规等）
- 第二单元：内科相关系统（心血管、呼吸、消化、泌尿、血液、内分泌、风湿）
- 第三单元：外科 + 妇产科 + 儿科
- 第四单元：精神神经、传染病、其他、预防医学等

> 应用类试题长期占约 50–55%，是命题绝对重心；"理解类"近年上升。

## 4. 命题导向（教师必须掌握的 4 个转向）

1. **临床化**：教材未明确的药物用法、临床情境判断增多，考"会用"而非"背过"。
2. **灵活化 / 细节化**：仍在大纲内，但出题角度变化，需换思路解题。
3. **应用类权重高**：强调把知识迁移到新情境解决临床实际问题。
4. **智能化命题**：医考中心推进 AI 与虚拟模拟在命题中的应用——临床病例库、
   医学影像题库、自动组卷、智能审校。教师可据此反向设计"特色模拟题"。

## 5. 教师工作映射

| 教研动作 | 对应本 Skill 模块 |
|----------|------------------|
| 精析真题、梳理高频考点 | Module B 精准分析 |
| 分值分布、命题规律统计 | Module C 考情归纳 |
| 集体备课、磨课、靶向教案 | Module D 讲解教学 |
| 真题思维融入课堂 | Module A + D 闭环 |
| AI 智能命题平台选题 | Module D（生成）→ A（入库） |
