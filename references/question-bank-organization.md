# 题库结构化采集与标注规范 · Question Bank Organization

> 把任意来源的考题变成**可追溯、可分析、可复用**的标准化记录。

## 1. 来源类型（Source Typology）

| 代码 | 来源 | 可信度 | 说明 |
|------|------|--------|------|
| REAL | 官方/授权真题 | 高 | 极少见完整公开 |
| RECALL | 考生回忆版 | 中 | 需交叉验证，标注置信度 |
| INST | 机构题库 | 中–高 | 主流培训机构，标注出处 |
| AI | 智能命制题 | 中 | 本 Skill Module D 生成，须标注"模拟" |
| FAC | 院校自编 | 中 | 教研室/题库，标注年份与适用 |

## 2. 标准元数据字段（每条必填/选填）

```
id            : 唯一编号（如 CL-2025-A2-0142）
year          : 考试年份（2024/2025/2026…）
exam_type     : 执业 / 助理
stage         : 技能 / 综合
unit          : 单元（一/二/三/四）
q_type        : A1 / A2 / A3 / A4 / B1
system        : 系统（如 心血管系统）
disease       : 疾病（如 急性心肌梗死）
exam_point    : 考点（映射大纲条款）
cognitive     : 记忆 / 理解 / 应用
difficulty    : 易 / 中 / 难
trap          : 命题陷阱（简述）
source        : REAL/RECALL/INST/AI/FAC + 具体出处
confidence    : 高/中/低（回忆版尤其重要）
tags          : 自由标签（如 #新增 #高频 #跨学科）
```

## 3. 采集流程

1. **收集**：从回忆版、机构题、院校卷、AI 生成中汇总原始题。
2. **清洗**：去重、补全题干、统一术语（以人卫版为准）。
3. **标注**：逐题填元数据（用 `templates/question-record-template.md`）。
4. **溯源**：每题绑定来源与置信度；AI 题必须标 `AI-模拟`。
5. **入库**：按 system → disease → exam_point 三级归档，便于后续聚合分析。

## 4. 质量门槛

- RECALL 题 Confidence=低 时，仅在"趋势参考"中使用，不进入正式分析结论。
- AI 生成题必须标注"模拟题，非真题"，禁止冒充官方题目。
- 同一考点跨年出现 ≥3 次 → 标记 `#高频`；当年新出现 → 标记 `#新增`。

## 5. 与下游模块的衔接

- 标注完成 → 直接喂给 Module B（精准分析）与 Module C（考情归纳）。
- AI 生成题经 Module B 分析后回流入库，形成"生成—分析—校验"闭环。
