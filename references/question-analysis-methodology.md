# 考题精准分析方法论 · Precise Question Analysis Methodology

> 对单题或批量题，产出可教学的精准分析。这是教师"精析真题"环节的方法底座。

## 1. 单题分析五维模型

| 维度 | 问题 | 输出要点 |
|------|------|----------|
| 考点映射 | 考什么？ | 大纲条款 + 人卫教材章节 + 关联指南 |
| 认知层次 | 考到哪层？ | 记忆 / 理解 / 应用（见 cognitive-level-framework） |
| 难度判定 | 多难？ | 易/中/难 + 判定依据 |
| 命题陷阱 | 怎么坑人？ | 干扰项逻辑、措辞误导、跨系统干扰 |
| 易错点 | 学生错哪？ | 典型错误路径 + 纠正策略 |

## 2. 分析步骤

1. **读题定位**：识别题型、系统、疾病、情境。
2. **考点溯源**：映射到 NHC 大纲条款；标注人卫版章节编号。
3. **认知判定**：判断该题主要测"记住/理解/应用"。
4. **陷阱拆解**：逐一审视每个选项为何对、为何错。
5. **难度归因**：综合认知层次、干扰强度、临床跨度给难度。
6. **教学转化**：提炼"一句话讲清"的讲解要点与纠错话术。

## 3. 批量分析聚合

对 N 道题批量分析后，可输出：

- 考点覆盖率（已覆盖大纲条款占比）
- 认知层次分布（记忆/理解/应用 占比）
- 难度分布（易/中/难 占比）
- 高频陷阱 Top10
- 系统/疾病热力图（哪类题最容易失分）

## 4. 教学转化示例话术

> "这道题表面考 X，本质考 Y。学生常选 C，是因为把 A 症状和 B 疾病混淆——
> 讲的时候要先拆'鉴别要点'，再用'一句话口诀'固化。"
